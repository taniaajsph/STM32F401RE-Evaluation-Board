# STM32F401RE-Evaluation-Board
A custom two-layer STM32F401RE evaluation/development board 
## Features

- STM32F401RE MCU
- 3.3 V regulated power supply
- USB-C interface
- SWD programming/debug interface
- Reset button
- BOOT0 configuration
- User button
- User LED
- Power LED
- UART interface
- SPI interface
- I²C interface
- Analog GPIO expansion
- Arduino-style digital GPIO expansion
- External HSE crystal
- MCU decoupling capacitors
- Two-layer PCB target
- Maximum board size: 100 mm × 100 mm

The board is designed as a compact, accessible development platform inspired by
the STM32 NUCLEO-F401RE while using an independently designed schematic and PCB
layout.

The expansion headers expose commonly used STM32 peripherals so that sensors,
displays and other external modules can be connected easily.

## Tools

- KiCad
- STM32F401RE
